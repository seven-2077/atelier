## 然后做完这些

1. 白天／黄昏／夜晚作为统一状态机平滑切换（约 2 秒量级），左下文字按钮可用。三段气质必须拉开：白天柔和日光把高台立面和低地石桥照清楚，暗部有颜色、不是脏灰，玻璃偏冷能倒出天空，切忌白模；黄昏保持已锁定的主样张方向；夜晚窗内亮度不一，檐下与露台灯笼从枝叶间透出，只照亮附近门阶、石纹、水面与叶背，水面映出暖灯与冷天色。不要全屏霓虹，不要假神光片。
2. 有限位的旋转和缩放：任何允许的机位都不得把入口、露台、石桥藏进花木或墙后，也不得挡住左侧刊名。
3. 少量海棠落花，不要铺成毯子。
4. 刊文字色随时段变化，叠在浅色花叶或粉墙上也要够对比。
5. 预览端口仍是 **5181**，host 127.0.0.1，strictPort。不要占用或杀掉 5174、5175、5180。
6. 必须实际跑起来。用无头 Chrome / puppeteer-core 截三张默认机位 1920×1080 静帧：
   - `01-refs/still-daylight.png`
   - `01-refs/still-golden-hour.png`
   - `01-refs/still-after-dark.png`
   不要打开系统 Chrome 窗口。
7. `npm run build` 必须通过。写诚实的 `.//00-brief/QA-REPORT.md`：已达线和未达线分开写，未完成的不要标成已交付。

## 对照已出的黄昏静帧，优先改这些

静帧在 `01-refs/direction-still-golden-hour.png`，自检见 `DIRECTION-STILL-REPORT.md`。默认机位和大落位不要改，只补未达线：

1. 把浅池的范围和岸线做清楚，水面要能读出，并能映一点暖灯与天色；石桥要像跨过水的石板桥，不要深色地面上的一块踏板。
2. 把低地补满：花窗、错落太湖石、石桌凳要能看见，池周不要大块空地。
3. 罗汉松改成深青针叶成簇，不要灰白枯枝感。
4. 天空去掉海报式硬切渐变，加强一点空气感；窗玻璃要能倒出天空；芭蕉减少大切面体块感。
5. 然后再做三段光、限位交互、少量落花和三张静帧，按上文其余条款执行。
