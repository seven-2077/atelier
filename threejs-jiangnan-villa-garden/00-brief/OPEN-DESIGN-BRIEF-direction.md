# OpenDesign 第 1 轮：黄昏方向静帧

模型必须是 **v4.1-flash-eco**（DeepSeek V4.1 Flash Eco）。工作目录必须是 `./`。只写这个目录。不要改、不要覆盖 `./` 和 `/workspace/threejs-konbini-shinkai-v2`。不要同步笔记本，不要推仓库。不要打开系统 Chrome 预览窗（会掐死 GPU）。

先通读并严格执行：

- `.//00-brief/COMPOSITION.md`
- `.//00-brief/BRIEF.md`
- `/workspace/aether-standards/miniature-diorama-quality-bar.md`

完成度要到达蓝花楹那一档（比质量，不抄那栋楼和那两棵树）。获肯定静帧只许只读对照：`.//01-refs/approved-2026-11-11/`。蓝花楹里白天偏平、花冠过密、浅色上文字对比弱，仍当作未解决，一开始就要避开。

## 本轮只要这些

1. 在 `02-scene/` 建可运行的 Vite + TypeScript + Three.js 页面（sRGB + ACESFilmic）。
2. 锁死 COMPOSITION.md 里的默认机位：16:9，略俯 22°–28°，垂直 FOV 32°–38°，三分之四侧，别墅与园子中偏右，左 30%–35% 给杂志文字和天空，近处可见微缩底座侧面。
3. 高低两层都要有完整设计：高台砌石挡墙、宅前平台、露台栏杆、石阶、近宅花木、一侧曲折罗汉松；低地粉墙浅池、月亮门、花窗、石板桥、太湖石、石桌凳、墙根灯笼、倚墙芭蕉、翠竹、池边海棠、初生荷叶。禁止用一道光秃斜坡连接房子和池水。
4. 只做一栋两层别墅：浅色墙身、黛瓦坡顶、木格窗与暖灯，一侧露台和石阶。入口、露台、低地石桥在默认机位必须可读。
5. 花木前低后高、形态互异、弯曲分叉、繁茂但透气。禁止圆球灌木和复制树形。
6. 本轮主光是黄昏：低角度暖光落在墙面、露台、挡墙和桥面上；池水与竹荫保持湿冷青。墙、瓦、暖木、砌石、水面、叶面材质要能读出差异。不要荧光霓虹，不要假神光片，不要白模。
7. 左侧中英混排生活方式杂志排版（文案按 COMPOSITION.md 自拟），叠在浅色花叶上也要够对比。不要社交控件、水印、品牌。
8. 预览端口必须是 **5181**，host 127.0.0.1，strictPort。不要占用或杀掉 5174、5175、5180。
9. 必须实际跑起来。用无头 Chrome / puppeteer-core 截一张默认机位黄昏静帧，1920×1080，存为 `.//01-refs/direction-still-golden-hour.png`。不要打开会掐死 GPU 的系统 Chrome 窗口。可参考蓝花楹工程的截帧思路，但不要改那个工程的文件。
10. `npm run build` 必须通过。写一份诚实的 `.//00-brief/DIRECTION-STILL-REPORT.md`：已达线和未达线分开写。

本轮不要先做完整的白天／夜晚切换、轨道交互和落花（左下时段文字可先占位）。先把这一帧黄昏方向静帧做够。

若要对照完成度，只读蓝花楹肯定稿，不要写那两个受保护目录。
