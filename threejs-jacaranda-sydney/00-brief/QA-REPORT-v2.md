# 蓝花楹微缩场景 — 打磨 v2 自检报告

未触碰：「日曜」便利店工程、5174、已锁定的 `01-refs/approved-2026-11-11/`、`01-refs/still-*.png` 原文件。未同步笔记本，未推仓库。

## 本轮实际改动

1. **白天光照（主项）**
   - 重排昼间光比：压低半球光（1.12 → 0.42）与环境光（0.46 → 0.14），太阳改为暖白、从右前上方塑形（强度 2.3，阴影 0.95），曝光 0.96 → 0.84。
   - 奶油立面基色加深（`#f6ecdb` → `#e3d1b8`），白模感减弱；檐口、阳台、窗套的投影更明确，转角背光面与正面分开。
   - 天空重做浅霾：顶部更收的蓝、地平提亮，渐变过渡拉开，去掉原来的海报蓝分层；加轻微大气霾（`skyHaze`），夜间/黄昏保持原值。
   - 窗玻璃不再是一整片死青：新增程序化天空反射 cube 与竖向玻璃色阶/斜向天空反光贴图，白天偏冷、有反射，窗与窗之间保留色差；夜晚暖窗仍由原 emissive 主导。
   - 沥青贴图提亮并加入轮迹，路面在白天有材质和反光；路面/人行道接入同一天空反射探针，夜间强度压低。
   - 白天左侧字色加深（`--ink`、`--accent`），scrim 改成更实的暖纸色并保留横向渐隐；`DAYLIGHT / GOLDEN HOUR / AFTER DARK` 与页脚在白天改用深色字，不再用象牙白压在浅底上。
2. **左树减密（主项）**
   - `main.ts` 中 seed 512 的左树 `cardDensity` 0.5 → 0.31。保留了下垂花序、弯曲分叉和与右树不同的轮廓，没有改成枯枝或圆球。
   - 右下裁切保留，长椅、门口、阳台、标题在默认机位和轨道两端均未新增遮挡。
3. **连带项**
   - 右侧路缘从 x=20.2 拉到 x=19.55，右路宽度 3.8 → 4.45，默认机位里右侧马路比之前略厚；相机未动。
   - `scripts/capture-still.mjs` 增加可选 `--azimuth=`，仅用于轨道两端自检，默认截帧行为不变。
   - 未加全屏 Bloom、没有神光片或霓虹。

## 是否还偏平 / 偏白模

- 比 v1 明显改善：正面不再是均匀一张白纸，檐口、阳台和窗套有可读投影，受光面偏暖、转角背光偏冷，立面有奶油色而不是纯白。
- **仍未完全解决**：长立面中上部在默认机位仍是一大片较亮的浅色，缺少更细的材质起伏和更明显的明暗过渡；它现在“像奶油建筑”，但还不是照片级的重量感。这个判断按未完成记，不计入已交差。

## 左树是否还偏密

- 比 v1 透气：树冠内部能看到天空、楼角和枝干，花卡成簇而不是整团实心；轮廓仍是左低右高的独立树形。
- **仍不算稀疏**：靠画面中心的一侧花量还比较足，个别角度会露出较细的内部枝条。若下一轮还要继续减，建议只微调这一侧，不要动整体轮廓。

## 可读性（默认机位 1920×1080）

- 圆弧门口：可读，门前踏步和暖色门斗清楚。
- 二层铁艺阳台：可读，栏杆花式仍在。
- 紫色长椅：可读，未被左树吞掉。
- 左侧 `SYDNEY` / `Jacaranda Days`：白天对比比 v1 强，字压在浅色花冠上仍能读；文案和排版结构未改。
- 轨道两端（约 -45.3° / -16.7°）已用 `--azimuth` 截帧检查，以上四处均可读；右下角裁切保留。

## 黄昏 / 夜晚回归

- 黄昏：天空、暖窗、路灯基本保持原样；左树减密后画面更透气。为避免白天玻璃改动影响黄昏，黄昏玻璃反射单独降到 0.3，窗内暖光仍是主调。
- 夜晚：窗、门廊、路灯仍是主光，路面没有被反射探针洗亮；左树变稀后标题区更干净。两者均未按白天思路重做。
- 右侧马路在夜晚仍偏窄，只是略有加宽，没有改变构图。
